# Aprender Programação — Arrastar Itens

Site estático de exemplo que demonstra uma interface para organizar tópicos de programaç��o por arrastar e soltar.

Como usar
1. Abra `index.html` no navegador (ou publique via GitHub Pages).
2. Arraste itens da "Caixa de Tópicos" para "Aprender Agora" ou "Projetos".
3. Dentro de cada coluna, arraste para reordenar.

Personalização
- Edite `index.html` para alterar tópicos e textos.
- Altere estilos em `styles.css`.
- A lógica de arrastar está em `script.js`.

Publicar
- Para publicar no GitHub Pages, coloque estes arquivos na branch `gh-pages` ou na branch default com GitHub Pages habilitado.
